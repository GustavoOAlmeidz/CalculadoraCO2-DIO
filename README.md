## 📖 Sobre o Projeto e Metodologia (AI-Driven Development)

A **Calculadora de Emissão de CO2** é uma ferramenta de conscientização ambiental desenvolvida durante o bootcamp "GitHub Copilot - Código na Prática" pela Digital Innovation One (DIO) em parceria com o GitHub.

O foco técnico deste repositório não é apenas a aplicação em si, mas a **metodologia de desenvolvimento**. Este projeto foi inteiramente codificado utilizando o **GitHub Copilot** como assistente de *Pair Programming*. 

O objetivo foi aplicar técnicas avançadas de engenharia de prompts diretamente na IDE para:
* Aumentar exponencialmente a velocidade de entrega (Produtividade).
* Automatizar a criação de *boilerplates* e estruturas repetitivas em HTML/CSS/JS.
* Garantir a qualidade da manipulação do DOM através da validação contínua do código gerado pela Inteligência Artificial.

## 🏗️ Arquitetura e Decisões Técnicas

Embora seja uma aplicação de interface cliente (*Client-side*), o código foi estruturado seguindo o princípio de **Separação de Responsabilidades (Separation of Concerns)**:

* **`/js` (Lógica de Negócio e DOM):** Regras matemáticas de cálculo de emissão isoladas da camada de apresentação, garantindo que o código seja testável e fácil de dar manutenção.
* **`/css` (Apresentação):** Estilização modular e responsiva, garantindo usabilidade em dispositivos móveis e desktops.
* **`.github/workflows` (CI/CD):** Implementação de pipelines automatizados via GitHub Actions para garantir a integridade do código e processos de integração contínua.
